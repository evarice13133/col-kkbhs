# Copobimat - School Management System

Application web de gestion scolaire développée en PHP orienté objet (POO).  
Elle permet de centraliser la gestion des utilisateurs, des données académiques et des opérations administratives.

---

## Fonctionnalités

- Authentification sécurisée des utilisateurs
- Gestion des élèves
- Gestion du personnel
- Suivi académique
- Organisation des classes et structures

---

## Stack technique

- PHP (POO)
- MySQL
- HTML / CSS
- JavaScript
- Architecture MVC
